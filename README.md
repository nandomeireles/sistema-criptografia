# 🔐 Sistema de Criptografia com Cifra de Vigenère

Projeto acadêmico desenvolvido utilizando a linguagem C, com foco em técnicas criptográficas, segurança da informação e comunicação segura por meio da criptografia polialfabética.

---

# 📖 Sobre o Projeto

Este projeto foi desenvolvido como uma atividade acadêmica da faculdade para aplicação prática dos conceitos de criptografia em um cenário fictício envolvendo segurança e controle de acesso.

O sistema simula uma operação da Guarda Costeira Brasileira, onde um navio contendo lixo tóxico radioativo foi apreendido próximo à costa brasileira. Para garantir comunicações seguras entre os inspetores autorizados, foi utilizada a técnica de criptografia conhecida como Cifra de Vigenère.

O programa permite realizar processos de criptografia e descriptografia de mensagens utilizando uma chave secreta personalizada, garantindo maior segurança nas comunicações.

---

# 🎯 Objetivo

O objetivo do projeto é demonstrar na prática o funcionamento de técnicas criptográficas, permitindo compreender como mensagens podem ser protegidas contra acessos não autorizados.

Além disso, o sistema busca apresentar conceitos fundamentais de segurança da informação, confidencialidade de dados e comunicação segura utilizando criptografia clássica.

# 🔒 Técnica Criptográfica Utilizada

O projeto utiliza a Cifra de Vigenère, uma técnica de criptografia polialfabética baseada no uso de uma chave secreta para realizar deslocamentos nas letras da mensagem original.

Essa técnica foi escolhida por possuir maior segurança em relação às cifras monoalfabéticas tradicionais, dificultando análises de frequência simples.
